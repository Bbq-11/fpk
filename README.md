# Витрина туристических поездов

Каталог путешествий по России с поиском и фильтрацией маршрутов.

Данные оставил локальными, так как для пяти поездов отдельное состояние и запросы к серверу были бы лишними.
Фильтры сохраняются в URL, поэтому после возврата к каталогу они не сбрасываются, а ссылкой на результаты можно поделиться.
Детальную информацию вынес на отдельный маршрут вместо модального окна, чтобы работали прямые ссылки и история браузера.

Стек: Vue 3, TypeScript, Vue Router, Vuetify, Vite.

Запуск: `npm ci && npm run dev`
Проверки: `npm run lint`, `npm run test:unit -- --run`, `npm run test:e2e -- --project=chromium`
Демо: https://fpk-trains.vercel.app
